## Collagen Reflectance Analyzer 1.2

### Downloads
Pick the zip for your computer. It is attached below a few minutes after this release appears.
- **CollagenAnalyzer-mac-apple-silicon.zip**: Macs with M1, M2, M3 or M4 chips
- **CollagenAnalyzer-mac-intel.zip**: older Intel Macs
- **CollagenAnalyzer-windows.zip**: Windows 10 and 11

Unzip the file and open the app. The user manual (PDF) is inside the zip. Your settings from 1.1 are kept.

**Mac:** the app is not signed by Apple, so macOS blocks it the first time (right-click → Open does not get around this). Drag **Collagen Analyzer.app** to Applications, then run this once in Terminal and open the app normally:
```
xattr -dr com.apple.quarantine "/Applications/Collagen Analyzer.app"
```

### New in 1.2
**Graphs you can take with you**
- Every graph in Results & plots, Patterns and the Experiment planner has **Copy**, **Save…** (PNG, PDF, SVG or TIFF, 300 dpi, white background) and **Full screen** (or double-click the graph; Esc goes back). Zoom and pan stay available.
- Planner: the response map can show the prediction only or the uncertainty only; **Save all graphs…** writes the map, effects and model check in one go; log axes are easier to read.

**Strongest correlations (Patterns)**
- A new **Correlations** tab ranks the strongest relations and lists the top three in plain words:
  - AMF settings vs each gel's change after AMF (including tile-type shares): which setting goes with more remodeling;
  - metric vs metric, per file or tile by tile inside images;
  - metric vs depth z within each z-stack.
- Each row gives Spearman's ρ, n (gels, files, images or z-stacks, never single tiles) and q (corrected for testing many pairs). Pairs linked by how they are measured are hidden by default. Click a row to plot it.

**Easier to use**
- **Recent analyses** on the Files step and under Results & plots → Recent: one click reopens earlier results on every results page.
- **Drag and drop** a results folder onto Results & plots, Patterns or the Experiment planner.
- **Sound and notification** when a run finishes, so you can work in other programs meanwhile.
- When something goes wrong, the app says **what happened and what to do** (no pixel size, not enough memory, files only in iCloud, no permission, damaged files, …).
- **Keyboard shortcuts**: ⌘/Ctrl + 1…6 pages, R run, S save graph, F full screen, ⌘/ lists them all.
- Every page **remembers its choices** between sessions.
- The app tells you when a **new version** is out (at most once a day; can be turned off on the Help page).
